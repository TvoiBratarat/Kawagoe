# Kawagoe Guide

A small Japanese travel guide website for Kawagoe, a historic town known for its traditional warehouse-style streets, sweet potato culture, and Edo-period atmosphere.

This project is built using plain HTML, CSS, and JavaScript with no frameworks or build tools.

## Features

- Intro hero section with a historic Kawagoe theme
- Timeline of key historical events
- Filterable attraction cards
- Countdown display for the bell chime time
- Light/dark theme toggle
- Responsive layout for desktop and mobile screens

## Project Structure

- `小江戸川越ガイド.html` — main page structure
- `styles.css` — page styling and responsive layout
- `script.js` — interactive behavior such as filtering, countdown, and theme switch

## How to Run

1. Open the project folder in a browser.
2. Open `小江戸川越ガイド.html` directly in your browser.
3. Or open https://tvoibratarat.github.io/Kawagoe/

No installation is required because the site uses static files only.

## Notes

- The site uses Google Fonts for the Japanese-style serif and sans-serif appearance.
- The theme preference is saved in the browser using `localStorage`.
- The bell countdown is based on Japan Standard Time (Asia/Tokyo).
