川越の歴史

水運と新田開発で栄え、大火のあとに蔵造りの町並みが生まれました。

  1. 1638年寛永の大火。のち松平信綱が城下を整備し、1639年に「十ヶ町四門前」の町割を定めます。
  2. 1655年松平信綱の命で野火止用水が開削されます。新河岸川の舟運（高瀬舟）で江戸と結ばれました。
  3. 元禄時代柳沢吉保が三富新田を開拓。落ち葉堆肥でサツマイモ栽培に適した土壌ができました。
  4. 1792年現存する最古の蔵造り、大沢家住宅（寛政4年）が建てられます。
  5. 1893年川越大火。1,302戸が焼失しましたが、焼け残った蔵造りの耐火性が見直され、商人たちが競って店蔵を再建しました。
  6. 1894年焼け落ちた時の鐘が再建されます（現在の4代目）。

栗（九里）より（四里）うまい十三里

江戸から十三里（約52km）の川越は、焼き芋ブームを背景にさつまいもの名産地として知られるようになりました。舟運で江戸へ直接運べたことと、関東ローム層と落ち葉堆肥による土づくりが理由です。

このサイトの技術

HTML・CSS・JavaScriptを分けて構成した、読みやすいマルチファイル形式のサイトです。

HTML

header / main / section など意味のあるタグで構成し、ナビやボタンにはaria属性を付けています。

CSS

カスタムプロパティで配色を管理し、Gridとclampでスマホからパソコンまで対応します。

JavaScript

スポットのデータを配列で持ち、絞り込み表示・時の鐘カウントダウン・テーマ切替を実装しています。
